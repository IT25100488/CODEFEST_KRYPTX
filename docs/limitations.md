# Limitations and Failed Approaches

## 1. What Works Well

- **Iterative Multi-Hop Retrieval**: Reliably connects facts across distant documents (novels, wiki entries, codex tables, and ephemera).
- **Domain-Grounded Generation**: Output answers are strictly grounded in retrieved archive passages with direct answers highlighted in bold and structured bulleted reasoning.
- **Deterministic Citation Verification**: Zero citation hallucination because sources are extracted directly from vector metadata instead of generated by the LLM.
- **Full-Stack End-to-End Execution**: Real-time integration from user prompt to FastAPI backend to Next.js UI with interactive evidence drawers.
- **Robust Error & Rate-Limit Handling**: Exponential backoff retry on external APIs and extended request timeouts to prevent transient 429 and 504 errors.

---

## 2. Failed Approaches & Lessons Learned

During the 2-week development cycle, the team tested several alternative architectures before converging on the final solution:

### Failed Approach 1: Single-Pass Dense Retrieval
- **Attempt**: Using high-k (top 20) single vector searches with Voyage AI and relying solely on the final LLM to synthesize the answer.
- **Failure**: In our benchmark evaluation across Track 1B questions, complete chain retrieval was only **14.29% (1/7)**. Later-hop evidence was buried outside the top candidates because the user's initial question rarely contains the terminology of the final resolution document.
- **Lesson**: Sub-track 1B fundamentally requires progressive entity discovery across documents.

### Failed Approach 2: Unconstrained LLM Query Expansion
- **Attempt**: Letting the LLM freely formulate any search queries it thought were relevant.
- **Failure**: The LLM frequently generated conversational queries (e.g., *"give me more information about the battle outcome"* or *"tell me if this person was involved"*) which degraded vector similarity search in dense embedding space.
- **Lesson**: Search queries must be concise, keyword-dense entity combinations (e.g., `["The Iron-Ring Cartel Leaden Accord", "The Iron-Ring Cartel victor"]`).

### Failed Approach 3: Unbounded Multi-Hop Looping
- **Attempt**: Allowing the agent to continue querying until it believed it had an answer.
- **Failure**: On ambiguous or under-specified archive questions, the agent entered query loops, exhausting API rate limits and causing request timeouts exceeding 90 seconds.
- **Lesson**: Hard upper limits (`MAX_HOPS = 3`, `MAX_TOTAL_EVIDENCE = 20`, query deduplication) are essential for predictable, robust enterprise performance.

### Failed Approach 4: Allowing the Answer LLM to Output Markdown Citations
- **Attempt**: Asking the answer LLM to cite document filenames and page numbers in its markdown text.
- **Failure**: The LLM occasionally invented filenames (e.g., citing `codex_vol_1.pdf` instead of `the_annals_of_the_ashen_era.pdf`) or cited documents not in the retrieved set.
- **Lesson**: Moved to deterministic metadata attachment: the LLM outputs numeric evidence IDs (`[1, 2]`), and the backend maps them to verified database chunks.

## 3. Current Limitations

1. **Free-Tier Gateway Latency**:
   - Because the system uses OpenRouter free-tier rotating endpoints, sequential multi-hop calls can introduce a 45–60s end-to-end response latency during peak traffic.
   - *Mitigation*: In an enterprise deployment, a dedicated self-hosted vLLM or private frontier model (e.g., Claude 3.5 Sonnet / GPT-4o) would reduce this to 5–8 seconds.

2. **Cross-Encoder Reranking Compute**:
   - Complex neural cross-encoders provide marginal precision gains over bi-encoders but introduce heavy local GPU dependencies.
   - *Mitigation*: Implemented a lightweight multi-factor composite heuristic ranker (`retrieval/evidence_ranker.py`) that scores chunks by vector distance, entity match count, and cross-reference frequency without GPU overhead.

3. **Conflicting In-World Sources**:
   - In the Ashen Era lore, tavern ballads occasionally contradict formal codex records. While the prompt instructs the model to acknowledge conflicting evidence, rare subtle discrepancies may require specialized credibility scoring.
