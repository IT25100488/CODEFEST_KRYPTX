4. Multi-Hop Query Planner Improvements
==================================================

USER:
One development question failed:
"Which accord was ultimately won by the faction of which Ederon Fellgard is a member?"

ASSISTANT:
Analyzed the failure chain:
Ederon Fellgard -> The Iron-Ring Cartel -> The Leaden Accord

Improved deterministic fallback logic so it:
- prioritizes named entities from the original question
- continues from newly discovered intermediate entities
- combines linked entities with relationship terms from the question
- supports hyphenated entity names such as "Iron-Ring Cartel"

After the fix, the question passed end-to-end.

5. Answer Generator Robustness
==================================================

USER:
The answer generator sometimes returned bad output or unreliable source filenames.

ASSISTANT:
Changed the answer generation strategy to structured JSON:

{
  "answer": "<direct concise answer>",
  "reasoning": "<short evidence-grounded explanation>",
  "evidence_ids": [1, 2]
}

Added parsing that:
- strips markdown fences
- extracts the first JSON object
- parses it safely

Changed source attribution so the LLM only selects evidence IDs and Python maps them back to the original retrieval metadata.

This fixed source filename hallucination / extension mismatches.

Also added a one-time retry when the LLM returns invalid JSON.

A real failure observed during testing was:

After the retry logic was added, the affected question passed.
